R-Browser blocks ads and trackers, refuses insecure connections, and locks down sites it doesn't know until they've been checked. It uses the web engine your computer already has, so it stays small and light. It's free and open source.

What it does

Blocks ads, trackers and pop-ups

EasyList, EasyPrivacy and Peter Lowe's list are built into the browser rather than added as an extension. Click the shield to turn blocking off for one site.

Only uses secure connections

Addresses starting with http are switched to https. If a site has no secure version, R-Browser asks before loading it.

Locks down sites it doesn't know

Sites outside the 10,000 most visited get an "Unverified" badge and open with JIT, WebAssembly, WebGL and WebRTC switched off. A one-time check looks for look-alike names, malware lists and pop-up tricks. Sites that pass run at full speed, and you can trust any site yourself.

Puts idle tabs to sleep

Tabs you haven't looked at for five minutes are unloaded and come back where you left them. A tab playing audio or holding a half-typed form is left alone.

Keeps your passwords

Saved passwords are encrypted with AES-256, with the key in your system keychain. You can import them from Google Passwords.

The usual things

Tab groups, dragging tabs into new windows, incognito, bookmarks, history, downloads and session restore. Updates install themselves and are signature-checked first.

Install

The download button above picks the right file for your computer. You can also get each file directly.

macOS 14 or later, Apple silicon

  1. Download R-Browser.app.tar.gz (7.2 MB) and unpack it.
  2. Move R-Browser to Applications.
  3. Open it. The app isn't notarized yet, so the first time macOS says it can't verify it: click Done, open System Settings → Privacy & Security, scroll down and click Open Anyway. macOS only asks once.

Windows 10 and 11, 64-bit

  1. Download R-Browser-Windows-Setup.exe (4.8 MB) and run it.
  2. If Windows says "Windows protected your PC", choose More info, then Run anyway. This goes away once the installer is code-signed.

Linux is planned. Older versions and release notes are on the releases page.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Windows installers will carry the signature once the project is approved.

  • Committers and reviewers: rahul428-2
  • Approvers: rahul428-2

Signed files are built from the public repository by GitHub Actions. Nothing built on a personal machine is signed.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The one automatic connection is the update check, which downloads a small file from this project's GitHub releases (see GitHub's privacy statement). Websites you visit, and the search engine you use (Google by default), receive what any browser sends them.
