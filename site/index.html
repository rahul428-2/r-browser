Installing

Version 0.1.0, free and open source under the Mozilla Public License 2.0. The download button picks the right file for your computer.

Windows 10 and 11

  1. Run R-Browser-Windows-Setup.exe (4.8 MB).
  2. If Windows says "Windows protected your PC", choose More info, then Run anyway. This goes away once the installer is code-signed.

macOS 13 or later, Apple silicon

  1. Unpack R-Browser.app.tar.gz (7.2 MB) and move R-Browser to Applications.
  2. The first time, right-click R-Browser and choose Open, because the app isn't notarized yet.

Both update themselves after that. Linux is planned. Older versions are on the releases page.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Windows installers will carry the signature once the project is approved.

  • Committers and reviewers: rahul428-2
  • Approvers: rahul428-2

Every signed file is built from the public repository by GitHub Actions. Nothing built on a personal machine is signed.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The one automatic connection is the update check, which downloads a small file from this project's GitHub releases (see GitHub's privacy statement). Websites you visit, and the search engine you use (Google by default), receive what any browser sends them.
